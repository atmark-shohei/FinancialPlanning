# 配当履歴アーカイブ

証券会社からダウンロードした配当・分配金の実績データを年ごとに保存する。

## ディレクトリ構成

```
data/dividends/
├── README.md
└── <年>/
    └── <証券会社>_<元のファイル名>.csv
```

## 保存ルール

1. **年ごとのフォルダに入れる**（`2026/`, `2027/` …）
2. ファイル名の先頭に**証券会社名**を付ける（複数社に対応するため）
3. 元のファイル名の日付部分は**そのまま残す**（ダウンロード時点が分かる）
4. **UTF-8（BOM付き）に変換して保存する**
   - 楽天証券のCSVは Shift-JIS（CP932）で出力される
   - BOM付きUTF-8にすると GitHub 上で正しく表示され、Excel でも文字化けしない
   - 変換コマンド:
     ```bash
     printf '\xEF\xBB\xBF' > 出力先.csv
     iconv -f CP932 -t UTF-8 元ファイル.csv >> 出力先.csv
     ```

## 判明した売却済み銘柄

配当履歴には載るが保有一覧にない銘柄＝権利確定後に売却したもの。

| 年 | コード | 銘柄 | 口座 | 受取配当 |
|---|---|---|---|---:|
| 2026 | 3002 | グンゼ | NISA成長投資枠 | 21,600 |
| 2026 | 3031 | ラクーンホールディングス | 特定・一般 | 5,100 |

**配当履歴は「売却済み銘柄の発見」に使える。** 保有一覧との差分を毎年チェックすること。

## 用途

- `FIRE_Strategy.md` 第2.6節の配当実績の裏付け
- 年次レビュー（第14章）での配当計画線との突合
- 増配・減配の推移の把握

## 注意

`.gitignore` で `*.csv` を除外しているため、このディレクトリだけ例外指定している。
**他の場所のCSVは自動では追跡されない。** 追加する場合は中身を確認してから。
